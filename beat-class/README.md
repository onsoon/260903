# BeAT(비트) 활용 1차시 수업 자료 (고등학생, 45분)

부산교육 AI 튜터 **BeAT**(https://beat.busanedu.net) 학생 교육 프로그램 리플릿을 바탕으로 만든 1차시 수업 패키지입니다.
AI 윤리 → 접속·로그인 → 질문(프롬프트) 잘하기 → 메뉴별 실습 → 돌아보기를 한 시간에 다룹니다.

| 파일 | 내용 |
| --- | --- |
| `practice-site.html` | 학생 실습 사이트 원본 (Claude 아티팩트로 게시) |
| `index.html` | 실습 사이트 단독 실행본 (브라우저로 바로 열기, 학교 서버·GitHub Pages에 올리기용) |
| `slides/` | 강의 슬라이드 원본 (19장, 발표자 노트에 시간·진행 멘트·정답 포함) |

## 수업 전 확인 (꼭!)

- [ ] **학생 로그인 방식**: 우리 학교 학생 계정으로 BeAT에 로그인하는 방법과 아이디·초기 비밀번호 안내를 확인하고, 슬라이드 9번 `[로그인 방식: 선생님 안내]` 칸을 바꿔 두기
- [ ] **수업GPT 카테고리**: 오늘 교과 자료(학습지·교과서 단원)를 내 카테고리에 올려 두기. 없으면 `BeAT활용안내 AI챗봇 → BeAT 활용 가이드 질문`으로 대신
- [ ] **AI Agents / Custom AI**: 진로·진학 Agent, 자기소개·번역 도구가 실제로 어떤 이름으로 있는지 열어 보기
- [ ] **실습 사이트 공유**: 아티팩트 공유(Share) 메뉴에서 학생용 링크를 만들거나 `index.html`을 학교 서버에 올리고, 슬라이드 13번에 주소·QR 넣기
- [ ] 학생 기기 준비 (가능하면 실습 사이트용 휴대폰 + BeAT용 크롬북/PC 두 화면)

## 메뉴별 실습 프롬프트

`[ ]` 칸은 학생이 자기 상황에 맞게 바꿔 씁니다.

### 수업GPT (모두 하기): 선생님 자료로 개념 정리

> 가는 길: 수업GPT → 왼쪽 카테고리 → 우리 학교_선생님 폴더 (없으면 BeAT활용안내 AI챗봇) → 대화 시작

```
이 자료에 나오는 핵심 개념 3가지를 고등학생 눈높이로 설명해 줘.
각 개념마다 자료의 어느 부분에 나오는지도 알려 줘.
마지막에 내가 이해했는지 확인하는 O/X 문제 2개를 내 줘. 정답은 내가 답한 뒤에 알려 줘.
```
확인: 선생님 자료를 바탕으로 한 답인가? / ‘어느 부분’을 실제로 찾아봤나? / O/X를 스스로 풀었나?

### 개인GPT: 어려운 개념을 내 관심사로 이해하기

> 가는 길: 개인GPT → 새 대화 → 질문 입력 (자료가 있으면 첨부)

```
나는 고등학교 [1]학년이야. [요즘 배우는 개념, 예: 광합성]을 [내가 좋아하는 것, 예: 게임]에 비유해서 3문장으로 쉽게 설명해 줘.
그다음 비유가 맞지 않는 부분이 있으면 하나 알려 주고, 확인 퀴즈 2개를 내 줘.
```
확인: 비유가 핵심을 담았나? / 교과서와 다른 곳은 없나? / ‘안 맞는 부분’을 이해했나?

### AI Agents: 관심사로 진로·학과 탐색하기

> 가는 길: AI Agents → 진로·진학 관련 Agent 찾기 → 대화 시작 (없으면 개인GPT)

```
나는 [좋아하는 것, 예: 영상 편집]에 관심이 많은 고등학생이야.
관련 대학 학과 3개를 표로 정리해 줘. 칸은 ‘학과 / 배우는 것 / 고등학교 때 해 볼 수 있는 활동’으로 해 줘.
확실하지 않은 정보는 ‘확인 필요’라고 표시해 줘.
```
확인: 개인정보를 넣지 않았나? / ‘확인 필요’는 대학 누리집에서 확인했나? / 내 생각을 한 줄 덧붙였나?

### Custom AI: 자기소개 피드백 받기 (대신 써 주기 X)

> 가는 길: Custom AI → 자기소개·면접 관련 도구 (없으면 번역 도구) → 대화 시작

```
아래는 내가 직접 쓴 자기소개 3문장이야.
대신 써 주지는 말고, 좋은 점 1개와 고치면 좋을 점 2개만 알려 줘. 고칠 방향은 질문 형태로 알려 줘.

[내가 쓴 자기소개 3문장, 이름·학교 이름은 빼고 쓰기]
```
번역 도구라면: 영어 교과서 문단 하나를 번역하게 한 뒤, 원문과 비교해 어색한 문장 1개 찾기.

확인: 개인정보를 뺐나? / AI 문장이 아니라 내 문장을 고쳤나? / 동의하지 않는 피드백이 있다면 이유는?

### 리플릿의 과목별 예시 질문

- 국어: 주장에 대한 반론이 들어왔을 때 논리적으로 재반박하려면 어떤 근거를 보강해야 할까?
- 영어: 이 문장에서 관계대명사와 관계부사 중 어떤 것을 써야 하는지 그 이유까지 자세히 알려 줘.
- 수학: 내가 푼 방식이 정답과 다른데, 풀이 과정 중 어느 단계에서 오류가 발생했는지 알려 줘.
- 사회·과학: 그래프에서 변수 간의 상관관계를 어떻게 해석하고 결론을 도출해야 할까?
