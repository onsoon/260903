# BeAT(비트) 활용 1차시 수업 자료 (고등학생, 45분)

부산교육 AI 튜터 **BeAT**(https://beat.busanedu.net) 학생 교육 프로그램 리플릿을 바탕으로 만든 1차시 수업 패키지입니다.
AI 윤리 → 접속·로그인 → 질문(프롬프트) 잘하기 → 메뉴별 실습 → 돌아보기를 한 시간에 다룹니다.

| 파일 | 내용 |
| --- | --- |
| `practice-site.html` | 학생 실습 사이트 원본 (Claude 아티팩트로 게시) |
| `index.html` | 실습 사이트 단독 실행본 (브라우저로 바로 열기, 학교 서버·GitHub Pages에 올리기용) |
| `slides/` | 강의 슬라이드 원본 (19장, 발표자 노트에 시간·진행 멘트·정답 포함) |
| `data/` | 메뉴별 실습 자료 8개 (학습지, 오답노트, 비문학 지문, 설문 CSV, 자기소개 초안, 영어 지문) |
| `tools/` | `make_data.py`: 실습 자료 생성 · `embed_files.py`: 자료를 사이트에 넣고 `index.html` 다시 만들기 |

## 수업 전 확인 (꼭!)

- [ ] **학생 로그인 방식**: 우리 학교 학생 계정으로 BeAT에 로그인하는 방법과 아이디·초기 비밀번호 안내를 확인하고, 슬라이드 9번 `[로그인 방식: 선생님 안내]` 칸을 바꿔 두기
- [ ] **수업GPT 카테고리**: `data/수업GPT_통합과학_탄소순환_학습지.docx`(실습 사이트에서도 내려받기 가능)를 내 카테고리에 올려 두기. 우리 반 교과 학습지로 바꿔도 되고, 등록이 어려우면 학생이 같은 파일을 개인GPT에 첨부
- [ ] **AI Agents / Custom AI**: 진로·진학 Agent, 자기소개·번역 도구가 실제로 어떤 이름으로 있는지 열어 보기
- [ ] **실습 사이트 공유**: 아티팩트 공유(Share) 메뉴에서 학생용 링크를 만들거나 `index.html`을 학교 서버에 올리고, 슬라이드 13번에 주소·QR 넣기
- [ ] 학생 기기 준비 (가능하면 실습 사이트용 휴대폰 + BeAT용 크롬북/PC 두 화면)

## 수업 지도안 (45분)

| 시간 | 단계 | 활동 | 슬라이드 | 실습 사이트 |
| --- | --- | --- | --- | --- |
| 0~5분 | 도입 | 오늘의 흐름, “이런 고민 있나요?” 손 들기, AI를 써 본 경험 나누기 | 1~3 | |
| 5~15분 | AI 윤리 | 상황 O/X 퀴즈, AI도 틀린다(할루시네이션), BeAT 안전 사용 약속 5가지 | 4~7 | ① 윤리 퀴즈, ② 안전 약속 |
| 15~22분 | BeAT 접속 | BeAT 소개, 로그인, 위쪽 메뉴 4개(수업GPT·개인GPT·AI Agents·Custom AI), 첫 질문 | 8~10 | ③ 접속하기 |
| 22~27분 | 질문 잘하기 | 역할 + 상황 + 요청 + 형식, 아쉬운 질문 고쳐 쓰기(짝 활동) | 11~12 | ④ 질문 만들기 |
| 27~40분 | 메뉴별 실습 | 수업GPT(모두) + 개인GPT·AI Agents·Custom AI 중 하나 이상, 답을 받은 뒤 확인 체크 | 13~17 | ⑤ 메뉴별 실습 |
| 40~45분 | 정리 | 돌아보기 세 줄 쓰기·발표, 후속 프로그램 안내 | 18~19 | ⑥ 돌아보기 |

**핵심 메시지**: 지키기(개인정보) · 확인하기(사실 확인) · 밝히기(출처 표시)

## 메뉴별 실습 (메뉴마다 2개 중 골라서)

`[ ]` 칸은 학생이 자기 상황에 맞게 바꿔 씁니다. 모든 실습은 ‘내가 먼저 해 보고 AI는 점검’하는 구조입니다.

### 수업GPT (모두 하기)

#### 1. 학습지 핵심만 콕 집어 정리하기
*“시험 2주 전인데 학습지가 한가득, 어디부터 봐야 할지 모르겠다면”*

- 가는 길: 수업GPT → 왼쪽 카테고리 → 선생님 폴더 (탄소 순환 학습지가 있는 곳) → 대화 시작
- 자료: `data/수업GPT_통합과학_탄소순환_학습지.docx`, `data/수업GPT_통합과학_탄소순환_학습지.txt`
- 참고: 선생님이 수업GPT에 학습지를 올려 두셨다면 받지 않아도 돼요. 없으면 학습지를 받아 개인GPT에 첨부해서 해도 돼요.

```
이 학습지에서 시험에 나올 만한 핵심 개념 5가지를 중요한 순서대로 뽑아 줘.
각 개념은 한 줄로 설명하고, 학습지의 몇 번 항목에 나오는지 알려 줘.
마지막에 내가 외워야 할 키워드만 모아서 ‘10초 복습 카드’처럼 정리해 줘.
```
확인: AI가 말한 항목 번호를 학습지에서 직접 찾아봤나요? / 학습지에 없는 내용이 섞여 있지 않나요? / 복습 카드를 내 노트에 옮겨 적었나요?

#### 2. 헷갈리는 개념 비교표 + 내 답 채점받기
*“‘온실 효과’랑 ‘지구 온난화’, 시험지만 보면 헷갈린다면”*

- 가는 길: 수업GPT → 같은 선생님 폴더 → 대화 이어 가기
- 자료: `data/수업GPT_통합과학_탄소순환_학습지.docx`, `data/수업GPT_통합과학_탄소순환_학습지.txt`

```
학습지를 바탕으로 ‘온실 효과’와 ‘지구 온난화’의 차이를 표로 비교해 줘. 칸은 ‘뜻 / 원인 / 좋은 점 또는 문제점 / 헷갈리지 않는 한 줄 팁’으로 해 줘.
그다음 학습지 6번 확인 문제 2번에 대한 내 답을 채점하고, 부족한 부분만 알려 줘.
내 답: [AI에게 묻기 전에 내가 직접 쓴 답]
```
확인: AI에게 묻기 전에 내 답을 먼저 썼나요? / 비교표 내용이 학습지와 같나요? / 채점 결과를 학습지 맨 아래 정답과 비교했나요?

### 개인GPT

#### 1. 수학 오답, 정답 말고 힌트로 다시 풀기
*“해설지를 봐도 ‘내가 왜 틀렸는지’는 모르겠다면”*

- 가는 길: 개인GPT → 새 대화 → 오답노트 첨부 (또는 오답 하나를 붙여 넣기)
- 자료: `data/개인GPT_수학_오답노트.docx`, `data/개인GPT_수학_오답노트.txt`

```
너는 친절한 수학 선생님이야. 첨부한 오답노트의 ‘오답 1’을 봐 줘.
정답은 바로 말하지 말고, 내 풀이에서 몇 번째 단계가 틀렸는지만 먼저 알려 줘.
내가 "힌트"라고 하면 고치는 방법을 한 단계씩만 알려 줘.
다 풀면 같은 유형의 연습 문제 1개를 내 줘.
```
확인: 틀린 단계를 알고 나서 내가 직접 고쳐 풀었나요? / 파일 맨 아래 정답과 맞춰 봤나요? / 연습 문제도 혼자 풀어 봤나요?

#### 2. 긴 지문, 내가 먼저 요약하고 AI에게 점검받기
*“비문학 지문을 다 읽고 나면 무슨 내용이었는지 기억이 안 난다면”*

- 가는 길: 개인GPT → 새 대화 → 지문 파일 첨부 (또는 본문 붙여 넣기)
- 자료: `data/개인GPT_비문학지문_추천알고리즘.txt`

```
첨부한 비문학 지문을 읽고 내가 먼저 3줄로 요약해 봤어.
내 요약: [지문을 읽고 내가 쓴 3줄 요약]
내 요약에서 빠진 핵심 내용과 잘못 이해한 부분을 알려 줘.
그다음 지문 내용과 맞는지 묻는 O/X 문제 3개를 내 주고, 핵심어 3개를 정리해 줘.
```
확인: AI에게 묻기 전에 내 요약을 먼저 썼나요? / AI가 짚은 부분을 지문에서 직접 찾았나요? / O/X 정답의 근거를 지문 문장으로 말할 수 있나요?

### AI Agents

#### 1. 좋아하는 것에서 시작하는 진로·학과 탐색
*“‘너 꿈이 뭐야?’라는 질문이 제일 어렵다면”*

- 가는 길: AI Agents → 진로·진학 관련 Agent 찾기 (없으면 개인GPT) → 대화 시작

```
나는 [좋아하는 것, 예: 영상 편집]에 관심이 많은 고등학생이야.
관련 대학 학과 3개를 표로 정리해 줘. 칸은 ‘학과 / 배우는 것 / 고등학교 때 해 볼 수 있는 활동’으로 해 줘.
확실하지 않은 정보는 ‘확인 필요’라고 표시해 줘.
```
확인: 이름·학교·성적 같은 개인정보를 넣지 않았나요? / ‘확인 필요’ 정보를 대학 누리집에서 찾아봤나요? / 표에 내 생각을 한 줄 덧붙였나요?

#### 2. 설문 데이터로 5분 발표 준비하기
*“수행평가 발표인데 데이터를 어떻게 읽어야 할지 막막하다면”*

- 가는 길: AI Agents → 발표·수행평가 관련 Agent 찾기 (없으면 개인GPT) → CSV 파일 첨부
- 자료: `data/AIAgents_가상설문_스마트폰과수면.csv`

```
첨부한 파일은 고등학생 40명의 스마트폰 사용과 수면에 대한 가상 설문 데이터야. 이 데이터로 5분 발표를 준비하려고 해.
1) 데이터에서 눈에 띄는 경향 3가지를 숫자와 함께 알려 줘.
2) 발표 자료에 넣으면 좋은 그래프 2가지와 그 이유를 알려 줘.
3) ‘상관관계’와 ‘인과관계’를 헷갈리지 않으려면 무엇을 조심해야 하는지 알려 줘.
4) 친구들이 할 만한 예상 질문 3개를 내 줘.
```
확인: AI가 말한 숫자(평균 등) 하나 이상을 엑셀이나 계산기로 직접 확인했나요? / ‘스마트폰이 수면 부족의 원인이다’라고 단정하지 않았나요? / 발표에서 가상 데이터라는 것을 밝힐 건가요?

### Custom AI

#### 1. 자기소개 피드백 받기 (대신 써 주기 X)
*“자기소개서 첫 문장에서 30분째 멈춰 있다면”*

- 가는 길: Custom AI → 자기소개·면접 관련 도구 → 대화 시작
- 자료: `data/CustomAI_자기소개_초안_예시.txt`
- 참고: 아직 내 글이 없다면 예시 초안(가상 학생 A)으로 연습해 보세요.

```
아래는 자기소개 초안이야. 대신 써 주지는 말고,
① 누구나 쓸 수 있는 문장 ② 가장 나다운 문장 ③ 순서를 바꾸면 좋을 부분을 알려 줘.
고칠 방향은 질문 형태로 알려 줘.

[내 자기소개 3~5문장 또는 예시 초안 · 이름과 학교는 빼기]
```
확인: 이름·학교 같은 개인정보를 빼고 넣었나요? / AI의 질문에 답하며 내가 직접 고쳐 썼나요? / 동의하지 않는 피드백이 있다면 이유를 말할 수 있나요?

#### 2. 영어 지문 번역하고 원문과 비교하기
*“영어 지문, 내 해석이 맞는지 확인할 방법이 없다면”*

- 가는 길: Custom AI → 번역 도구 → 지문 붙여 넣기 (또는 파일 첨부)
- 자료: `data/CustomAI_영어지문_번역연습.txt`

```
아래 영어 지문을 자연스러운 한국어로 번역해 줘.
번역한 뒤 원문과 번역을 한 문장씩 나란히 표로 보여 주고,
고등학생이 꼭 알아야 할 단어 5개를 뜻과 예문으로 정리해 줘.

[영어 지문 붙여 넣기]
```
확인: AI 번역을 보기 전에 첫 문단을 내가 먼저 해석해 봤나요? / 뜻이 어색하거나 달라진 문장을 하나 찾았나요? / 단어 뜻 하나 이상을 사전으로 확인했나요?

모두 수업 연습용으로 새로 만든 예시 자료이며, 설문 데이터와 자기소개 속 인물은 가상입니다. 자료를 고치려면 `tools/make_data.py`를 수정한 뒤 `python3 tools/make_data.py && python3 tools/embed_files.py`를 실행하고 아티팩트를 다시 게시하세요.

### 리플릿의 과목별 예시 질문

- 국어: 주장에 대한 반론이 들어왔을 때 논리적으로 재반박하려면 어떤 근거를 보강해야 할까?
- 영어: 이 문장에서 관계대명사와 관계부사 중 어떤 것을 써야 하는지 그 이유까지 자세히 알려 줘.
- 수학: 내가 푼 방식이 정답과 다른데, 풀이 과정 중 어느 단계에서 오류가 발생했는지 알려 줘.
- 사회·과학: 그래프에서 변수 간의 상관관계를 어떻게 해석하고 결론을 도출해야 할까?
