# BeAT(비트) 활용 1차시 수업 자료 (고등학생, 45분)

부산교육 AI 튜터 **BeAT**(https://beat.busanedu.net) 학생 교육 프로그램 리플릿을 바탕으로 만든 1차시 수업 패키지입니다.
AI 윤리 → 접속·로그인 → 질문(프롬프트) 잘하기 → 메뉴별 실습 → 돌아보기를 한 시간에 다룹니다.

| 파일 | 내용 |
| --- | --- |
| `practice-site.html` | 학생 실습 사이트 원본 (Claude 아티팩트로 게시) |
| `index.html` | 실습 사이트 단독 실행본 (브라우저로 바로 열기, 학교 서버·GitHub Pages에 올리기용) |
| `slides/` | 강의 슬라이드 원본 (20장, 발표자 노트에 시간·진행 멘트·정답 포함) |
| `data/` | 메뉴별 실습 자료 8개 (학습지, 오답노트, 비문학 지문, 설문 CSV, 자기소개 초안, 영어 지문) |
| `tools/` | `make_data.py`: 실습 자료 생성 · `embed_files.py`: 자료를 사이트에 넣고 `index.html` 다시 만들기 |

## 수업 전 확인 (꼭!)

- [ ] **학생 로그인 방식**: 우리 학교 학생 계정으로 BeAT에 로그인하는 방법과 아이디·초기 비밀번호 안내를 확인하고, 슬라이드 10번 `[로그인 방식: 선생님 안내]` 칸을 바꿔 두기
- [ ] **수업GPT 카테고리**: `data/수업GPT_통합과학_탄소순환_학습지.docx`(실습 사이트에서도 내려받기 가능)를 내 카테고리에 올려 두기. 우리 반 교과 학습지로 바꿔도 되고, 등록이 어려우면 학생이 같은 파일을 개인GPT에 첨부
- [ ] **AI Agents / Custom AI**: 학교·공유 Agent에 과목 선택·진로 도우미가 있는지, ‘Agent 새로 만들기’의 분류 목록과 참고 문서 등록 가능 여부, Custom AI의 자기소개·번역 도구 이름 확인하기
- [ ] **실습 사이트 공유**: 아티팩트 공유(Share) 메뉴에서 학생용 링크를 만들거나 `index.html`을 학교 서버에 올리고, 슬라이드 14번에 주소·QR 넣기
- [ ] 학생 기기 준비 (가능하면 실습 사이트용 휴대폰 + BeAT용 크롬북/PC 두 화면)

## 안전 약속을 그림으로: 이미지 생성 프롬프트

실습 사이트 2번 탭에서 약속을 체크하면 ‘약속을 그림으로’ 도구가 열립니다. 체크한 약속 중 그림에 담을 것을 고르고(1개는 한 장면, 여러 개는 컷 만화), 스타일(웹툰·3D·수채화·픽셀아트·플랫 포스터), 분위기, 화면 비율, 한글 문구 여부를 고르면 프롬프트가 완성됩니다. BeAT 개인GPT에 붙여 넣어 이미지를 만듭니다. 시간이 빠듯하면 일찍 끝낸 학생 활동이나 과제로, 여유가 있으면 모둠별로 약속 하나씩 맡아 학급 포스터를 만듭니다.

| 약속 | 짧은 문구 | 장면 |
| --- | --- | --- |
| 개인정보를 입력하지 않아요 | 내 정보는 내가 지켜요 | 이름표·전화번호 카드를 자물쇠 상자에 넣고 AI 로봇 튜터가 엄지 척 |
| AI 답변이 정확한지 다시 확인해요 | AI 답도 한 번 더 확인! | AI 답변 말풍선과 교과서를 나란히 놓고 돋보기로 비교 |
| 출처를 표시해요 | 출처는 꼭 밝혀요 | 발표 화면 속 그림 아래에 ‘AI 생성 이미지’ 꼬리표 붙이기 |
| 그대로 제출하지 않아요 | 내 생각으로 고쳐 써요 | AI가 건넨 초안에 빨간 펜으로 고쳐 쓰고 내 생각 덧붙이기 |
| 이상한 답변은 알려요 | 이상하면 선생님께! | 물음표 구름 같은 답변이 뜨자 손 들어 선생님께 알리기 |

예시 (약속 1개, 기본 설정):

```
밝은 웹툰 스타일로 그림을 그려 줘.
주제: BeAT 안전 사용 약속 ‘개인정보를 입력하지 않아요.’
장면: 고등학생이 노트북 앞에서 이름표와 전화번호가 적힌 카드를 자물쇠 달린 보물상자에 넣고, 옆에서 AI 로봇 튜터가 엄지를 치켜세우는 장면
등장인물: 교복을 입은 한국 고등학생(실제 인물이 아닌 캐릭터)과 친근한 파란색 AI 로봇 튜터 ‘비트’
분위기: 밝고 따뜻한 느낌
화면 비율: 세로 3:4 (학급 게시판 포스터)
색감: 파란색과 분홍색 포인트, 깔끔한 흰 배경
글자: 그림 안에는 글자를 넣지 마. 문구는 내가 나중에 직접 넣을게.
조건: 실제 사람 얼굴, 연예인, 유명 만화 캐릭터는 쓰지 마. 학교 게시판에 붙일 수 있게 밝고 안전한 그림으로 그려 줘.
```

그림을 받은 뒤 확인: 손가락·얼굴·글자가 이상한 곳은 없나? / 그림만 보고도 약속의 뜻이 전해지나? / ‘AI 생성 이미지(BeAT)’라고 표시했나? / 친구나 내 얼굴 사진을 올려서 만들지 않았나?

## 메뉴별 실습 (메뉴마다 2개 중 골라서)

`[ ]` 칸은 학생이 자기 상황에 맞게 바꿔 씁니다. 모든 실습은 ‘내가 먼저 해 보고 AI는 점검’하는 구조입니다.

### 수업GPT (모두 하기)

#### 1. 학습지 핵심만 콕 집어 정리하기
*“시험 2주 전인데 학습지가 한가득, 어디부터 봐야 할지 모르겠다면”*

- 가는 길: 수업GPT → 왼쪽 카테고리 → 선생님 폴더 (탄소 순환 학습지가 있는 곳) → 대화 시작
- 자료: `data/수업GPT_통합과학_탄소순환_학습지.docx`, `data/수업GPT_통합과학_탄소순환_학습지.txt`
- 참고: 선생님이 수업GPT에 학습지를 올려 두셨다면 받지 않아도 돼요. 없으면 학습지를 받아 개인GPT에 첨부해서 해도 돼요.

```
이 학습지에서 시험에 나올 만한 핵심 개념 5가지를 중요한 순서대로 뽑아 줘.
각 개념은 한 줄로 설명하고, 학습지의 몇 번 항목에 나오는지 알려 줘.
마지막에 내가 외워야 할 키워드만 모아서 ‘10초 복습 카드’처럼 정리해 줘.
```
확인: AI가 말한 항목 번호를 학습지에서 직접 찾아봤나요? / 학습지에 없는 내용이 섞여 있지 않나요? / 복습 카드를 내 노트에 옮겨 적었나요?

#### 2. 헷갈리는 개념 비교표 + 내 답 채점받기
*“‘온실 효과’랑 ‘지구 온난화’, 시험지만 보면 헷갈린다면”*

- 가는 길: 수업GPT → 같은 선생님 폴더 → 대화 이어 가기
- 자료: `data/수업GPT_통합과학_탄소순환_학습지.docx`, `data/수업GPT_통합과학_탄소순환_학습지.txt`

```
학습지를 바탕으로 ‘온실 효과’와 ‘지구 온난화’의 차이를 표로 비교해 줘. 칸은 ‘뜻 / 원인 / 좋은 점 또는 문제점 / 헷갈리지 않는 한 줄 팁’으로 해 줘.
그다음 학습지 6번 확인 문제 2번에 대한 내 답을 채점하고, 부족한 부분만 알려 줘.
내 답: [AI에게 묻기 전에 내가 직접 쓴 답]
```
확인: AI에게 묻기 전에 내 답을 먼저 썼나요? / 비교표 내용이 학습지와 같나요? / 채점 결과를 학습지 맨 아래 정답과 비교했나요?

### 개인GPT

#### 1. 수학 오답, 정답 말고 힌트로 다시 풀기
*“해설지를 봐도 ‘내가 왜 틀렸는지’는 모르겠다면”*

- 가는 길: 개인GPT → 새 대화 → 오답노트 첨부 (또는 오답 하나를 붙여 넣기)
- 자료: `data/개인GPT_수학_오답노트.docx`, `data/개인GPT_수학_오답노트.txt`

```
너는 친절한 수학 선생님이야. 첨부한 오답노트의 ‘오답 1’을 봐 줘.
정답은 바로 말하지 말고, 내 풀이에서 몇 번째 단계가 틀렸는지만 먼저 알려 줘.
내가 "힌트"라고 하면 고치는 방법을 한 단계씩만 알려 줘.
다 풀면 같은 유형의 연습 문제 1개를 내 줘.
```
확인: 틀린 단계를 알고 나서 내가 직접 고쳐 풀었나요? / 파일 맨 아래 정답과 맞춰 봤나요? / 연습 문제도 혼자 풀어 봤나요?

#### 2. 긴 지문, 내가 먼저 요약하고 AI에게 점검받기
*“비문학 지문을 다 읽고 나면 무슨 내용이었는지 기억이 안 난다면”*

- 가는 길: 개인GPT → 새 대화 → 지문 파일 첨부 (또는 본문 붙여 넣기)
- 자료: `data/개인GPT_비문학지문_추천알고리즘.txt`

```
첨부한 비문학 지문을 읽고 내가 먼저 3줄로 요약해 봤어.
내 요약: [지문을 읽고 내가 쓴 3줄 요약]
내 요약에서 빠진 핵심 내용과 잘못 이해한 부분을 알려 줘.
그다음 지문 내용과 맞는지 묻는 O/X 문제 3개를 내 주고, 핵심어 3개를 정리해 줘.
```
확인: AI에게 묻기 전에 내 요약을 먼저 썼나요? / AI가 짚은 부분을 지문에서 직접 찾았나요? / O/X 정답의 근거를 지문 문장으로 말할 수 있나요?

### AI Agents

#### 1. 학교·공유 Agent로 과목 선택 상담하기
*“고교학점제 과목 선택, 뭘 골라야 할지 모르겠다면”*

- 가는 길: AI Agents → 왼쪽 Agent 목록 → 학교 Agent 또는 공유 Agent → 과목 선택·진로 도우미 고르기
- 참고: 우리 학교 Agent가 없으면 공유 Agent 중 과목 선택·진로 관련 Agent를 고르고, 입력창 아래 ‘다른 Agent와 대화하기’로 바꿀 수 있습니다.

```
나는 [관심 분야, 예: 생명과학·의료]에 관심이 있는 [1]학년이야.
우리 학교 교육과정에서 2학년 때 들으면 좋을 선택 과목 3개를 이유와 함께 추천해 줘.
과목마다 무엇을 배우는지, 어떤 진로와 연결되는지도 알려 줘.
학교 교육과정 자료에서 확인되지 않는 내용은 ‘확인 필요’라고 표시해 줘.
```
확인: 추천 과목이 우리 학교 교육과정표에 실제로 있는가? / 개인정보를 넣지 않았나? / 담임·진로 선생님께 여쭤볼 질문을 하나 적었나?

#### 2. 나의 Agent 만들기: 내 공부 스타일대로
*“매번 같은 부탁을 길게 쓰기 귀찮다면, 나만의 공부 도우미를 만들어요”*

BeAT ‘Agent 새로 만들기’ 화면 순서: **Agent 기본**(분류*, 공유 대상, 아이콘*, Agent 이름*, Agent 설명* 200 Byte) → **Agent 역할**(Agent 프롬프트*, 마술사, 시작 프롬프트) → **Agent 설정** → 미리보기 → 저장

- 공유 대상은 처음에는 비워 두고(나만 쓰기), 공유는 선생님 확인 뒤에 합니다.
- 마술사로 프롬프트를 다듬은 뒤에도 [지킬 것] 부분이 남아 있는지 확인합니다.

##### 템플릿: 시험 대비 퀴즈 코치

| 칸 | 입력 예시 |
| --- | --- |
| 분류 | 학습 (목록에서 가장 가까운 것) |
| 공유 대상 | 처음에는 선택하지 않기 (나만 쓰기) |
| 아이콘 | 마음에 드는 아이콘 하나 |
| Agent 이름 | 통합과학 퀴즈 코치 |
| Agent 설명 | 학습지 내용으로 한 문제씩 퀴즈를 내고 틀린 개념을 다시 설명해 주는 시험 대비 도우미 (118 Byte, UTF-8 기준) |
| 시작 프롬프트 | 탄소 순환 단원으로 5문제 내 주세요 / 제가 자주 틀리는 개념만 다시 물어봐 주세요 / O/X 문제로만 빠르게 10개! |
| Agent 설정 | Agent 설정에서 참고 문서를 올릴 수 있으면 ‘탄소 순환 학습지’를 등록하세요. 문제가 학습지 범위 안에서만 나와요. |

Agent 프롬프트:

```
너는 고등학생의 시험 공부를 돕는 퀴즈 코치야.
[진행 방법]
1. 처음에 단원과 문제 수(기본 5문제)를 물어본다.
2. 객관식, O/X, 단답형을 섞어 한 번에 한 문제씩 낸다.
3. 학생이 답하면 맞았는지 알려 주고, 틀리면 정답을 바로 말하지 말고 힌트를 한 번 준다.
4. 다 끝나면 맞힌 개수와 다시 볼 개념 2개를 정리한다.
[지킬 것]
- 학습 자료에 없는 내용은 문제로 내지 않고, 확실하지 않으면 ‘확인 필요’라고 말한다.
- 학생의 이름, 학교, 전화번호 같은 개인정보를 묻지 않는다.
- 친근한 존댓말로, 답변은 짧게 한다.
```
미리보기 시험: 시작 프롬프트를 누르고 일부러 틀린 답을 해 보세요. 정답 대신 힌트를 주면 성공!

##### 템플릿: 영어 단어 짝꿍

| 칸 | 입력 예시 |
| --- | --- |
| 분류 | 학습 (목록에서 가장 가까운 것) |
| 공유 대상 | 처음에는 선택하지 않기 (나만 쓰기) |
| 아이콘 | 마음에 드는 아이콘 하나 |
| Agent 이름 | 영어 단어 짝꿍 |
| Agent 설명 | 시험 범위 영어 단어를 뜻 맞히기와 예문 빈칸 채우기 게임으로 함께 외워 주는 도우미 (115 Byte, UTF-8 기준) |
| 시작 프롬프트 | 단어 10개 보낼게요, 뜻 맞히기부터! / 틀린 단어만 다시 퀴즈 내 주세요 / 오늘 외운 단어로 짧은 이야기 만들어 주세요 |
| Agent 설정 | 영어 지문 자료의 단어(circadian rhythm, melatonin 등)로 시험해 봐도 좋아요. |

Agent 프롬프트:

```
너는 고등학생과 영어 단어를 함께 외우는 공부 짝꿍이야.
[진행 방법]
1. 학생이 외울 단어 목록을 보내면 단어 수를 확인한다.
2. 한 번에 한 단어씩 ‘뜻 맞히기’ 또는 ‘예문 빈칸 채우기’ 문제를 낸다.
3. 틀린 단어는 기억해 두었다가 마지막에 한 번 더 묻는다.
4. 끝나면 틀린 단어와 외우기 쉬운 연상법을 표로 정리한다.
[지킬 것]
- 예문은 고등학교 수준의 쉬운 문장으로 만든다.
- 뜻이 여러 개인 단어는 시험에 자주 나오는 뜻을 먼저 알려 준다.
- 칭찬은 짧게, 문제는 빠르게 낸다.
```
미리보기 시험: 단어 5개를 보내고 하나를 일부러 틀려 보세요. 마지막에 그 단어를 다시 물어보면 성공!

##### 템플릿: 수행평가 발표 코치

| 칸 | 입력 예시 |
| --- | --- |
| 분류 | 진로·활동 (목록에서 가장 가까운 것) |
| 공유 대상 | 처음에는 선택하지 않기 (나만 쓰기) |
| 아이콘 | 마음에 드는 아이콘 하나 |
| Agent 이름 | 수행평가 발표 코치 |
| Agent 설명 | 발표 자료와 데이터를 보고 발표 흐름, 예상 질문, 말하기 연습을 도와주는 발표 코치 (113 Byte, UTF-8 기준) |
| 시작 프롬프트 | 설문 데이터로 5분 발표를 준비하고 있어요 / 예상 질문 3개로 리허설해 주세요 / 발표 첫 문장을 더 끌리게 고치고 싶어요 |
| Agent 설정 | 미리보기 대화에 ‘가상 설문 데이터(CSV)’를 첨부해서 시험해 보세요. |

Agent 프롬프트:

```
너는 고등학생의 수행평가 발표를 도와주는 발표 코치야.
[진행 방법]
1. 먼저 발표 주제, 발표 시간, 듣는 사람을 물어본다.
2. 학생이 자료나 데이터를 올리면 핵심 메시지 1개와 발표 흐름(도입-본론-마무리)을 제안한다.
3. 데이터가 있으면 눈에 띄는 경향을 숫자와 함께 정리하되, 상관관계를 원인과 결과로 단정하지 않는다.
4. 친구들이 할 만한 예상 질문 3개를 내고, 학생이 답하면 피드백한다.
[지킬 것]
- 발표 대본을 통째로 써 주지 않고, 학생이 직접 말할 수 있게 질문과 힌트로 돕는다.
- 출처가 필요한 내용은 출처를 밝히라고 알려 준다.
```
미리보기 시험: “대본 다 써 줘”라고 부탁해 보세요. 대본 대신 질문과 힌트로 도와주면 성공!

확인: 미리보기에서 시작 프롬프트를 눌러 시험했나? / 틀린 답이나 엉뚱한 부탁에도 정한 규칙대로 답하나? / 공유 대상을 ‘나만’으로 두고 저장했나? / 설명이 200 Byte 이하인가?

### Custom AI

#### 1. 자기소개 피드백 받기 (대신 써 주기 X)
*“자기소개서 첫 문장에서 30분째 멈춰 있다면”*

- 가는 길: Custom AI → 자기소개·면접 관련 도구 → 대화 시작
- 자료: `data/CustomAI_자기소개_초안_예시.txt`
- 참고: 아직 내 글이 없다면 예시 초안(가상 학생 A)으로 연습해 보세요.

```
아래는 자기소개 초안이야. 대신 써 주지는 말고,
① 누구나 쓸 수 있는 문장 ② 가장 나다운 문장 ③ 순서를 바꾸면 좋을 부분을 알려 줘.
고칠 방향은 질문 형태로 알려 줘.

[내 자기소개 3~5문장 또는 예시 초안 · 이름과 학교는 빼기]
```
확인: 이름·학교 같은 개인정보를 빼고 넣었나요? / AI의 질문에 답하며 내가 직접 고쳐 썼나요? / 동의하지 않는 피드백이 있다면 이유를 말할 수 있나요?

#### 2. 영어 지문 번역하고 원문과 비교하기
*“영어 지문, 내 해석이 맞는지 확인할 방법이 없다면”*

- 가는 길: Custom AI → 번역 도구 → 지문 붙여 넣기 (또는 파일 첨부)
- 자료: `data/CustomAI_영어지문_번역연습.txt`

```
아래 영어 지문을 자연스러운 한국어로 번역해 줘.
번역한 뒤 원문과 번역을 한 문장씩 나란히 표로 보여 주고,
고등학생이 꼭 알아야 할 단어 5개를 뜻과 예문으로 정리해 줘.

[영어 지문 붙여 넣기]
```
확인: AI 번역을 보기 전에 첫 문단을 내가 먼저 해석해 봤나요? / 뜻이 어색하거나 달라진 문장을 하나 찾았나요? / 단어 뜻 하나 이상을 사전으로 확인했나요?
