학교·공유 Agent로 과목 선택 상담

관심 분야를 말하고 2학년 선택 과목 3개 추천받기, 배우는 내용·연결 진로, 불확실하면 ‘확인 필요’

AI Agents → 학교 Agent / 공유 Agent → 과목 선택 도우미

확인: 우리 학교 교육과정표와 비교

“매번 같은 부탁, 길게 쓰기 귀찮아”

나의 Agent 만들기

분류 · 아이콘 · 이름 · 설명(200 Byte) → Agent 프롬프트(역할·진행 방법·지킬 것) → 시작 프롬프트 → 미리보기 → 저장

템플릿: 퀴즈 코치 · 영어 단어 짝꿍 · 발표 코치

공유 대상은 ‘나만’으로 시작

BeAT 1차시 · 17 · Agent 프롬프트에 [지킬 것]을 꼭 넣어요

[31:00~38:00 선택 실습] ① 왼쪽 Agent 목록의 학교 Agent·공유 Agent에서 과목 선택 도우미(예: ○○고 과목 선택 도우미)를 고릅니다. 우리 학교 Agent가 없으면 공유 Agent 중 진로·과목 관련 Agent를 쓰고, 입력창 아래 ‘다른 Agent와 대화하기’로 바꿀 수 있습니다. 추천 과목은 반드시 우리 학교 교육과정표와 비교하게 하세요. ② ‘Agent 새로 만들기’ 화면은 Agent 기본(분류, 공유 대상, 아이콘, 이름, 설명 200 Byte) → Agent 역할(Agent 프롬프트, 마술사, 시작 프롬프트) → Agent 설정 순서입니다. 실습 사이트에 같은 순서로 채운 템플릿 3개(퀴즈 코치, 영어 단어 짝꿍, 발표 코치)가 있어 칸마다 복사해 붙여 넣으면 됩니다. 마술사로 프롬프트를 다듬은 경우에도 [지킬 것](개인정보 묻지 않기, 대신 해 주지 않기)이 남아 있는지 확인시키세요. 공유 대상은 처음에는 비워 두고(나만), 공유는 선생님 확인 뒤에 합니다. 미리보기에서 일부러 틀린 답이나 “대본 다 써 줘” 같은 부탁을 해서 규칙대로 답하는지 시험하는 것이 핵심입니다. 수업 전 확인: 분류 목록에 어떤 항목이 있는지, Agent 설정에서 참고 문서를 올릴 수 있는지.
