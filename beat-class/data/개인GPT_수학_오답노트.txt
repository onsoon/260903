오답 1. 이차방정식 (근의 공식)
문제: 이차방정식 x² - 6x + 5 = 0 의 두 근을 구하시오.
1. a = 1, b = -6, c = 5
2. 근의 공식 x = (-b ± √(b² - 4ac)) / 2a 에 대입한다.
3. x = (-6 ± √(36 - 20)) / 2
4. x = (-6 ± 4) / 2
5. 내 답: x = -1 또는 x = -5

오답 2. 나머지정리
문제: 다항식 P(x) = x³ - 2x² + 3x - 4 를 x - 2 로 나눈 나머지를 구하시오.
1. 나머지정리에 따라 나머지는 P(-2) 이다.
2. P(-2) = (-2)³ - 2·(-2)² + 3·(-2) - 4
3. = -8 - 8 - 6 - 4
4. 내 답: 나머지는 -26

오답 3. 이차부등식
문제: 이차부등식 x² - x - 6 < 0 의 해를 구하시오.
1. 좌변을 인수분해하면 (x - 3)(x + 2) < 0
2. x = 3, x = -2 가 경계이다.
3. 내 답: x < -2 또는 x > 3

정답 확인용 (AI와 먼저 풀어 본 뒤에 보기)
- 오답 1: x = 1 또는 x = 5 (3단계에서 -b 는 +6 이어야 함)
- 오답 2: 나머지는 P(2) = 2 (x - a 로 나눈 나머지는 P(a))
- 오답 3: -2 < x < 3 (곱이 음수이면 두 근 사이)
