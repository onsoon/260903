# 🌱 우리집 습관 체크

초등 4학년·중학교 1학년 아이의 **생활습관 → 공부습관**을 단계적으로 길러 주는 체크리스트 사이트입니다.
기획 내용은 [SITE_PLAN.md](SITE_PLAN.md)에 있습니다.

## 주요 기능

- **아이별 화면**: 초등 화면(밝고 큼직하게) / 중등 화면(어둡고 깔끔하게)
- **오늘의 체크**: 생활·공부·가족 탭, 진행률, 모두 완료하면 축하 화면
- **연속 기록 🔥**: 하루 80% 이상 달성한 날이 이어지면 늘어나요. 항목별 연속 기록도 표시
- **이번 주 기록**: 요일 × 항목 표로 한 주 달성 현황과 주간 달성률
- **3단계 로드맵**: 생활 기본기 → 공부 준비 → 자기주도 공부. 2주 연속 80%면 다음 단계 제안
- **부모 모드 (비밀번호, 처음엔 `0000`)**: 아이 추가·별명·단계, 항목 추가·수정·순서·요일, 기본 템플릿 불러오기, 백업/복원
- **체크리스트 나눔**: 추천 템플릿 담기, 우리 집 체크리스트를 링크/파일로 공유 (항목만 담기고 아이 정보·기록은 포함되지 않음)

데이터는 기본적으로 **이 기기의 브라우저(localStorage)**에 저장됩니다.

## 구글 시트 연결 (가족 기기 연동)

부모 모드 → **구글 시트 연결**에서 우리 집 구글 시트를 연결하면 아이 기기와 부모님 폰이 같은 기록을 봅니다.
기록은 각 가정의 구글 드라이브에만 저장되고, 사이트에는 서버가 없습니다.

1. 새 구글 시트 → 확장 프로그램 → Apps Script → [`apps-script/Code.gs`](apps-script/Code.gs) 붙여 넣기
2. `setup` 함수 실행 → 권한 허용 (체크기록 · 항목 · 설정 탭 생성)
3. 배포 → 새 배포 → 웹 앱 (실행: 나, 액세스: 모든 사용자) → 웹 앱 URL 복사
4. 사이트에 웹 앱 URL과 `설정` 탭 B1의 가족 비밀키 입력

사이트 안의 "구글 시트 준비 방법 보기"에도 같은 안내와 코드 복사 버튼이 있습니다.
체크는 기기에 먼저 저장된 뒤 시트로 보내지고(오프라인이어도 나중에 전송), 30초마다·화면에 돌아올 때마다 시트와 맞춥니다.
같은 칸을 두 기기에서 바꾸면 나중에 바꾼 쪽이 남습니다.

## 배포 (GitHub Pages)

`main` 브랜치에 올라가면 `.github/workflows/pages.yml`이 자동으로 빌드·배포합니다.
처음 한 번만 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 바꿔 주세요.
주소: https://onsoon.github.io/260903/

## 실행

```bash
npm install
npm run dev      # http://localhost:3000
```

정적 파일만 필요하면 `npx vite build` 후 `dist/` 폴더를 아무 정적 호스팅(GitHub Pages, Netlify 등)에 올리면 됩니다.

## 폴더 구조

```
src/
├── App.tsx                 홈(아이 선택)과 화면 전환
├── data.ts                 타입, 기본 템플릿
├── logic.ts                날짜·달성률·연속 기록 계산, 공유 링크
├── store.ts                localStorage 저장, 백업 파일
├── sync.ts                 구글 시트 동기화
├── theme.ts                초등/중등 화면 색상
└── components/
    ├── ChildView.tsx       오늘의 체크 · 이번 주 기록
    ├── Celebration.tsx     완료 축하 화면
    ├── ParentMode.tsx      부모 모드
    ├── SharePage.tsx       체크리스트 나눔
    ├── SheetSync.tsx       구글 시트 연결 카드 · 준비 안내
    └── Confirm.tsx         확인 창
apps-script/Code.gs         구글 시트에 붙여 넣는 연결 스크립트
```
