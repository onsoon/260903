# 부산 시그니처 향수 랩 (실습 사이트)

「생성형 AI를 활용해 만드는 나만의 향수와 브랜딩」 수업용 실습 작업지입니다.
설치 없이 `index.html` 파일 하나로 동작하며, 입력 내용은 학습자 브라우저(localStorage)에만 저장됩니다.

## 구성
- **수업 노트**: Scent-Tech 활용 사례, 발향 단계(탑·미들·베이스), 프롬프트 공식과 질문 팁 8가지
- **1단계 향료 고르기**: 6가지 향료(시트러스·프루티·부케·솝·머스크·바닐라 엠버) 중 노트별 선택 + 나의 컨셉
- **2단계 컨셉 설정**: 선택이 자동 입력된 "AI 조향사" 프롬프트 복사 → 답변 붙여넣기 → 특징 1·2 선택
- **3단계 10ml 레시피**: 레시피 프롬프트 + 비율 슬라이더 계산기(ml·방울 수, 20:80 블렌딩 반영) + 마크다운 표 미리보기
- **4단계 이름 짓기**: 이름 추천 프롬프트 → 이름과 뜻 입력
- **5단계 SNS 홍보**: 퓨샷 러닝 홍보글 프롬프트 + 부산 장소(감천문화마을·다대포·범어사·전포카페거리·해운대·광안대교) 이미지 프롬프트
- **완성 라벨**: 입력 내용으로 향수 라벨과 공유용 결과 요약 생성

## 사용 방법
- 로컬: `perfume-lab/index.html`을 브라우저로 열기
- 배포: GitHub Pages 등 정적 호스팅에 `perfume-lab/` 폴더를 그대로 올리면 됩니다.
